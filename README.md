# ASCII Art Generator

A small Python GUI app that converts images into ASCII art.

## Setup

```bash
cd ascii-art
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## How to use

1. Click **Choose Image** and pick a photo (PNG, JPG, etc.).
2. Adjust **Width** if you want more or less detail (40–200).
3. Click **Generate** to see the ASCII preview.
4. Click **Save as .txt** to export the result.

## Requirements

- Python 3.10+
- Pillow (Tkinter is included with Python)
